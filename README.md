# Fab's Foot ⚽

Application React + TypeScript + Vite connectée à TheSportsDB.

## Fonctionnalités

- Tableau de bord football
- Matchs du jour
- Résultats et calendriers par compétition
- Classements
- Meilleurs buteurs
- Liste des compétitions disponibles
- Recherche de clubs
- Gestion des états chargement / erreur
- Rafraîchissement manuel
- Interface responsive sombre

## Installation

1. Installer Node.js 20+.
2. Installer les dépendances :

```bash
npm install
```

3. Lancer en développement :

```bash
npm run dev
```

4. Construire :

```bash
npm run build
```

## Remarque

Ce projet utilise actuellement l'API publique TheSportsDB, donc il ne dépend pas de variables d'environnement `VITE_*` pour fonctionner.
